FREE NASSAU: CHART TABLE ASSET PROMPTS

so the game ships and looks right today. These prompts are OPTIONAL upgrades: each one swaps a code-drawn placeholder for
real generated art. Generate with the same tool you used for the concept images. Export PNG or WebP, then drop the files
into img/chart/ using the file names below and tell me; I will wire them in (each swap is one CSS line or one SVG replacement).
